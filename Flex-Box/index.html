  4. Margin: Espacio exterior. Empuja a los vecinos.

El Problema Matemático 🧮

Si tengo un `div` con width: 200px, y le agrego padding: 20px y border: 5px...

¿Cuánto espacio real ocupa en la pantalla?

250px! (200 + 20 izq + 20 der + 5 izq + 5 der)

¡Por esto sus diseños se rompen al poner porcentajes (ej. 50% + 50%) y añadir bordes!

La Solución Mágica ✨


* {
    box-sizing: border-box;
}

Obliga al navegador a incluir el padding y border DENTRO del ancho que definiste.

Regla: Esto debe ir en TODOS sus proyectos.

Introducción a
Flexbox

(Flexible Box Layout)

¿Qué es Flexbox?

Un módulo de diseño CSS para alinear y distribuir espacio en UNA DIMENSIÓN (filas o columnas).

Resuelve problemas complejos de alineación que antes requerían trucos con float o márgenes negativos.

La Regla de Oro: Padres e Hijos 👨‍👧‍👦

  • Flex Container (Padre): El elemento que tiene display: flex;. Dicta las reglas.
  • Flex Items (Hijos): Los elementos hijos directos. Ellos obedecen.

Nota: Los "nietos" no se ven afectados directamente por el padre flex.

Activando el Poder


.contenedor {
    display: flex;
}

Efecto Inmediato: Todos los hijos se colocan en línea horizontal.

Geometría Flexbox:
Los Dos Ejes

Main Axis & Cross Axis

  • Main Axis (Eje Principal): La dirección principal en la que fluyen los elementos.
  • Cross Axis (Eje Cruzado): Perpendicular al eje principal.

flex-direction

Define cuál será el Eje Principal.


.padre { flex-direction: row; /* o column */ }

Propiedades de los Hijos 👶

¿Qué pasa si sobra espacio y queremos que un hijo crezca?

flex-grow

grow: 1
grow: 2
grow: 1

El elemento morado exige tomar el doble del espacio sobrante que sus hermanos.

flex-shrink

¿Qué pasa si FALTA espacio? Define la capacidad de un elemento para encogerse.


.hijo-resistente { flex-shrink: 0; /* 0 = NO te encojas, mantén tu tamaño */ }
.hijo-normal { flex-shrink: 1; /* 1 = Encógete si es necesario (Por defecto) */ }

Útil para logos, íconos o imágenes que no queremos que se deformen cuando la pantalla se hace pequeña.

flex-basis

El tamaño ideal o inicial del elemento antes de que empiece a crecer (grow) o encogerse (shrink).


.hijo { flex-basis: 250px; } /* Funciona como width o height dependiendo del eje principal */

Es mucho más seguro y semántico usar flex-basis que width cuando estamos trabajando dentro de un contenedor Flexbox.

El Atajo Definitivo: flex

Nadie en la vida real escribe grow, shrink y basis por separado. Usamos la propiedad abreviada.


/* Sintaxis: flex: grow | shrink | basis */
.hijo { flex: 1 0 200px; }

Traducción: "Crece si hay espacio de sobra (1), nunca te encojas si falta espacio (0), y tu tamaño ideal de partida es 200px".

El Truco Definitivo (El Santo Grial) 🏆

Centrar cualquier cosa vertical y horizontalmente:


.centrador-perfecto {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh; /* Requiere altura definida */
}

Manejando el Desbordamiento 🌊

flex-wrap

Por defecto, Flexbox intentará aplastar todos los hijos en una sola línea (nowrap).


.padre { flex-wrap: wrap; }

Con wrap, si no caben, saltan a la siguiente línea abajo. ¡Clave para grillas de productos!

align-content (Varias Líneas)

Solo funciona si hay flex-wrap: wrap y el contenido ocupa múltiples líneas. Distribuye todo el bloque de líneas en el eje cruzado (muy similar a justify-content pero en el otro eje).

El Atajo del Padre: flex-flow

Combina flex-direction y flex-wrap en una sola línea de código.


.padre { 
    /* Sintaxis: flex-direction | flex-wrap */
    flex-flow: row wrap; 
}

La Maravilla Moderna: gap ✨

Olvídense de los márgenes confusos para separar elementos y lidiar con el margen extra al final. gap crea un espacio exacto solo entre los ítems.


.padre { gap: 20px; /* o '10px 20px' para fila/columna */ }

Desafío de Clase 💻

Crear un Navbar

Requisitos:

  • Un contenedor <nav> padre.
  • Un logo <h1> a la izquierda.
  • Una lista <ul> a la derecha.
  • Los enlaces deben estar en horizontal.
  • ¡Prohibido usar float o márgenes automáticos para alinear! Todo con Flexbox.
