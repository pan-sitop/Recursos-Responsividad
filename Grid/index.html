Flexbox vs. CSS Grid 🥊

¿Cuándo usar cuál?

Flexbox (1 Dimensión)

Diseñado para controlar una sola línea a la vez: Fila O Columna.

Úsalo para: Navbars, listas de iconos, botones, componentes pequeños.

Grid (2 Dimensiones)

Diseñado para controlar el espacio simultáneamente en Filas Y Columnas.

Úsalo para: La estructura global de la página, galerías de imágenes complejas, layouts de periódico.

Nota: ¡Son amigos! Puedes tener un Grid Layout general y que adentro las áreas usen Flexbox.

Anatomía de la Rejilla 🧬

El vocabulario para no perderse.

Conceptos Clave

  1. Grid Container: El padre con display: grid;.
  2. Grid Item: Los hijos directos.
  3. Grid Line: Las líneas divisorias (se numeran).
  4. Grid Track: El espacio entre dos líneas (una fila o columna entera).
  5. Grid Cell: Una celda individual.
  6. Grid Area: Un rectángulo formado por varias celdas unidas.

Construyendo los Cimientos 🏗️

grid-template-columns y rows

Definimos explícitamente cuántas pistas queremos y de qué tamaño.


.contenedor {
    display: grid;
    grid-template-columns: 100px 200px 100px; /* 3 columnas */
    grid-template-rows: 150px 150px; /* 2 filas */
}

La Unidad Flexible: fr (Fraction)

Olvídate de los porcentajes difíciles. fr calcula el espacio libre disponible y lo reparte en proporciones.


/* El espacio se divide en 4 (1+2+1). La del medio es el doble de grande. */
.padre { grid-template-columns: 1fr 2fr 1fr; }

La Función repeat()

No repitas código como un robot. Usa matemáticas simples.


/* Mal: */
grid-template-columns: 1fr 1fr 1fr 1fr 1fr;

/* Bien: */
grid-template-columns: repeat(5, 1fr);

El Espacio: gap

Al igual que en Flexbox, define las "calles" entre tus filas y columnas.


.padre {
    gap: 20px; /* Aplica 20px a filas y columnas */
    /* row-gap: 10px; */
    /* column-gap: 30px; */
}

Posicionando Hijos (Método Numérico) 🔢

Expandiendo un Item (Spanning)

Por defecto un hijo ocupa una celda. Para hacerlo más grande usamos grid-column y grid-row.


.hijo-header {
    /* Empieza en la línea 1 y termina en la línea 4 */
    grid-column: 1 / 4; 
}
.hijo-alto {
    /* Empieza donde esté, y ocúpame 2 celdas hacia abajo */
    grid-row: span 2;
}

Nota: Si tienes 3 columnas, tienes 4 líneas divisorias. Se cuenta la línea, no la celda.

El Método Visual:
grid-template-areas 🎨

Dibujando la estructura con texto.

Paso 1: Dar nombre a los hijos

Asignamos una etiqueta interna a cada elemento HTML con grid-area.


.cabecera { grid-area: header; }
.barra-lateral { grid-area: sidebar; }
.contenido { grid-area: main; }
.pie-pagina { grid-area: footer; }

Paso 2: Dibujar en el Padre


.contenedor {
    display: grid;
    grid-template-columns: 1fr 3fr; /* Dos columnas */
    grid-template-areas: 
      "header header"
      "sidebar main"
      "footer footer";
}

El Truco para Espacios Vacíos

Si quieres dejar una celda completamente vacía en tu diseño, usa un punto ..


grid-template-areas: 
    "header header header"
    "sidebar . main" /* El medio estará vacío */
    "footer footer footer";

Alineación dentro de las celdas 🎯

justify-items y align-items

Se aplica al Padre. Controla cómo se alinean TODOS los hijos dentro de su propia celda. (Valores: start, end, center, stretch).


.padre { justify-items: center; /* Alinea en eje X dentro de la celda */ }
.padre { align-items: center;   /* Alinea en eje Y dentro de la celda */ }

justify-content y align-content

Se aplica al Padre. Controla la cuadrícula ENTERA si el contenedor es más grande que las pistas definidas.


/* Si mi contenedor mide 1000px y mi grid suma solo 500px... */
.padre { justify-content: center; /* Centra el grid entero al medio del div */ }

El Atajo Definitivo: place-items y place-content

Escribe todo de golpe (Alineación Y / Alineación X).


.padre {
    /* align-items + justify-items */
    place-items: center center; 
}

Desafío de Clase 💻

El Periódico Moderno

Requisitos:

  • HTML: <header>, <nav>, <main>, dos <aside> para publicidad, y <footer>.
  • Usar CSS Grid con grid-template-areas.
  • Las columnas deben ser: 1fr (PubliIzq), 3fr (Main), 1fr (PubliDer).
  • El Header y el Footer deben atravesar toda la pantalla.
